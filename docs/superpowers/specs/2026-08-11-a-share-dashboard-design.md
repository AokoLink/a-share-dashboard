# A股三层分析看板 — 设计文档

- **日期**: 2026-08-11
- **状态**: 需求已确认,待实施
- **目标目录**: `C:\stock`

## 1. 目标与范围

做一个本地运行的 A 股分析看板,用于**中短线波段**风格的投资决策辅助。核心诉求:

- **三层分析**:大盘总览 → 板块强弱(含板块级情绪)→ 个股量价体检
- **数据 + 明确结论**:基于规则打分,直接给出"哪个方向建议关注、哪个方向有风险",同时保留图表和指标数据供用户自行验证
- **盘中可用**:手动刷新 + 可选自动刷新(默认关闭)
- **界面**:本地网页看板(Flask 后端 + ECharts 前端)

### 范围外(本期不做)
- 东方财富板块热力图、北向资金(数据源被网络屏蔽)
- 实盘下单、买卖信号推送
- AI 大模型解读(可选后续)
- 周K/月K/分钟K(以日K + 分时为核心)

## 2. 环境与数据源约束

- Python 3.13 / miniconda,akshare 1.18.84,需安装 flask
- **可用数据源**:新浪(Sina)、腾讯(Tencent)、同花顺(THS)
- **被屏蔽数据源**:东方财富(East Money)、网易(连接被重置)
- 结论:所有数据获取必须避开 `xxx_em` 函数,改用新浪/腾讯/同花顺

已验证可行的数据接口:
- 新浪全市场实时快照 `stock_zh_a_spot()`(约 5541 只,含涨跌幅/成交额,耗时约 10s)
- 新浪指数日线 `stock_zh_index_daily(symbol='sh000001')`
- 新浪个股日线/分钟线 `stock_zh_a_daily` / `stock_zh_a_minute`
- 同花顺板块列表 `stock_board_industry_name_ths`(90 行业)/ `stock_board_concept_name_ths`(375 概念)
- 同花顺板块摘要 `stock_board_industry_summary_ths` / `stock_board_concept_summary_ths`
- 同花顺板块指数日线 `stock_board_industry_index_ths`
- 腾讯实时盘口 `qt.gtimg.cn/q=sh600519`

分三个相互独立的层,通过明确的接口协作:
- **数据层**只负责取数和缓存,不涉及业务判断
- **分析层**只吃数据层产出,输出打分与结论,不关心数据从哪来
- **API 层**组合两者,向前端输出 JSON

## 4. 数据层 (`data_source.py`)

每个函数负责一件事、带 TTL 内存缓存。缓存策略:数据放内存,按 key + 过期时间;过期后重新拉取,失败时返回上次缓存并标记 stale。

| 函数 | 数据源 | 缓存 | 用途 |
|---|---|---|---|
| `get_market_spot()` | 新浪全市场快照 | 60s | 计算全市场情绪统计 |
| `get_index_realtime()` | 新浪指数实时 | 30s | 上证/深成/创业板实时涨跌 |
| `get_index_daily(code)` | 新浪指数日线 | 10min | 大盘K线 |
| `get_sector_summary(type)` | 同花顺板块摘要 | 60s | 板块强弱榜单 |
| `get_sector_index_history(code)` | 同花顺板块指数日线 | 30min | 板块K线 |
| `get_stock_daily(code)` | 新浪个股日线(前复权) | 10min | 个股K线 |
| `get_stock_minute(code)` | 新浪个股分时 | 60s | 分时图 |
| `get_stock_quote(code)` | 腾讯实时盘口 | 30s | 个股实时报价 |

## 5. 分析打分层 (`analysis.py`)

三层打分,权重均为代码常量,便于调优。

### 5.1 大盘总览(不给单一情绪结论)

只输出背景数据:三大指数涨跌、全市场上涨/下跌/平家数、涨停/跌停数、总成交额、较昨日量能变化。**不做整体情绪分** —— 情绪判断落到板块层。

### 5.2 板块打分(核心:板块级情绪)

每个板块(行业/概念)独立计算三个分,互不干扰,体现"科技情绪高涨、创新药低迷"的结构分化:

**板块情绪分** — 这个板块今天的人气冷暖:
- 板块内上涨家数占比(40%)
- 板块内涨停家数(20%)
- 板块成交额放量程度(25%,对比板块近期均值)
- 领涨股强度(15%)

**板块强度分** — 方向的力量与持续性:
- 板块指数涨幅(40%)
- 连续上榜天数(30%,连续 N 日进入涨幅榜前列)
- 资金活跃度(30%,成交额相对全市场占比)

**板块风险分** — 追高与回撤风险:
- 单日涨幅过热(>5%)、3 日累计涨幅过大(>10%)
- 放量滞涨(涨幅收窄但量能放大)
- 板块内严重分化(上涨家数占比失衡)

**结论矩阵**(情绪 + 强度 + 风险 组合):

| 情绪 | 强度 | 风险 | 结论 |
|---|---|---|---|
| 高 | 高 | 低 | ✅ **建议关注** |
| 高/中 | 高 | 高 | ⚠️ **谨慎追高** |
| 低 | — | — | 👀 **观望** |
| — | 低 | 高 | 🚫 **风险提示/回避** |

### 5.3 个股量价打分

基于日K的个股体检:

- **趋势分**:MA5/10/20/60 多头排列、站上关键均线(MA20/MA60)
- **量价分**:放量突破、量比 >1.5 且量价齐升、缩量健康回踩
- **信号分**:MACD 金叉/死叉、突破近期平台高点
- **风险项**:乖离率偏离 MA20 >15%、放量滞涨、放量跌破 MA20、高位长上影
- **结论**:✅关注 / 🔶持有 / ⚠️回调风险 / 🚫规避

## 6. API 层 (`app.py`)

| 路由 | 返回 |
|---|---|
| `GET /api/market` | 大盘总览 + 情绪统计 |
| `GET /api/sectors?type=industry\|concept` | 板块强弱列表(含三围分+结论) |
| `GET /api/sector/<code>` | 板块详情:指数K线、三围分、成分股列表 |
| `GET /api/stock?code=600519` | 个股详情:K线、成交量、分时、量价分、结论 |
| `GET /` | 看板页面 |

所有接口返回 JSON;数据源失败时返回缓存 + `{"stale": true}`。

## 7. 前端 (`templates/index.html` + `static/app.js`)

单页看板,布局自上而下、自左而右:

```
顶栏:标题 | 更新时间 | 手动刷新按钮 | 自动刷新开关
大盘总览条:上证/深成/创业板涨跌 | 涨/跌/平家数 | 涨停/跌停 | 总成交额
板块榜单(主区)               | 右侧详情区
 · 行业/概念切换              |  · 选板块 → 板块指数K线+三围分+结论+成分股
 · 按综合评分排序              |  · 选个股 → 日K线+MA+成交量图、分时图、量价评分卡
 · 颜色=结论(绿/黄/灰/红)      |
自选股条:⭐ 自选(localStorage)快速点击查看
```

**交互**:
1. 打开页面自动拉大盘 + 板块榜单
2. 点板块行 → 右侧加载板块详情(含成分股)
3. 点成分股或搜索框输代码 → 右侧加载个股详情
4. "加入自选" → 存 localStorage,底部自选条
5. 手动刷新 → 重拉全量;失败时右上角"⚠️ 数据可能过期"并沿用旧数据
6. 自动刷新开关 → 每 60s 刷大盘+板块(右侧当前选中对象一并刷新)

**图表**(ECharts 本地打包):板块K线(蜡烛+MA)、个股K线(蜡烛+MA+成交量副图)、分时图(价格线+均价线+分时量)。

## 8. 错误处理

- 每个数据源请求带超时(约 15s),失败重试 1 次
- 重试仍失败 → 返回上次缓存 + `stale: true`,前端显示过期提示
- 首次运行无缓存时失败 → 返回 `error` 字段,前端给出明确报错信息
- 板块成分股接口因 akshare 版本函数名差异,实施时先确认正确函数名(`stock_board_industry_info_ths` 等),再接线
