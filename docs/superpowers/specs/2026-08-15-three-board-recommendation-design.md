# 三板块推荐(短线 / 波段 / 长线)设计

**Goal:** 把「推荐」从单一"个股精准推荐"重构为三块,每块明确「信号是什么、谁选股、输出什么、诚实标注什么」。核心原则:短线做已验证的恐慌择时(并采用"持有 2-3 天"新结论),波段让用户自己选股 + regime 启发式择时,长线只做定性参考。杜绝把已证伪的选股 edge 或未回测的退出信号包装成验证 alpha。

## 背景:约束来源(为什么每块长这样)

本轮盲测 + 历史证伪记录确立的硬事实(全部真实数据,非臆测):

1. **选股精准已证伪**:composite 对 T+1 方向 Spearman ≈ 0.02;摆动持有期 T+5/T+10 弱正 tilt ~0.03-0.04,但扛不住 40bp 成本,不可交易。→ 任何"算法精选个股"都不成立。
2. **逆向择时是唯一真实杠杆**:恐慌→抄底(日级净胜率 66%,精确二项 p=0.0275),高潮/退潮→空仓。但只在**进场/回避**上验证过,**不是退出信号**。
3. **恐慌反弹到 T+3 不衰减**:持有 2 天净胜率 73.17%(+1.32%)、3 天 73.17%(+1.69%),边际 day2 +0.45%/day3 +0.34% 递减仍正 → 默认持有 2-3 天。但 41 天样本、肥左尾,禁止再细分。
4. **A 股 T+1**:合法窗口 oo(T+1开→T+2开)/oc;扩展 T+1开→T+3/4开。od(当日)与 close1 非法。成本 40bp 往返。

## Global Constraints(所有实现任务必须遵守)

- [C1] 无算法选股 alpha:任何板块不得声称"算法精选大涨股";个股打分不构成选股 edge。
- [C2] regime 仅作进场/回避信号;任何"持有/卖出"指引是启发式,必须在 UI 显式标注"启发式(未回测为退出信号)"。
- [C3] 恐慌信号 41 天样本:禁止细分"好/坏恐慌",禁止在 41 天内做参数优化;持有期固定为默认 2-3 天,不做逐日择时卖出优化。
- [C4] 长线是定性参考、非回测:必须标注"高不确定、非回测、仅供决策参考";不生成伪精确分数;不进推荐页当"荐股"。
- [C5] A 股 T+1:只用合法窗口(oo/oc 及其到 T+3/4 扩展);禁 od/close1。成本 40bp 往返。
- [C6] 工程约束:Python 源只用 ASCII `-`(禁 U+2212);`_analysis/` gitignored,探针永不提交;`code2sector.json` 用 GBK 打开;直接提交 main;每改必跑测试。

## Board 1 — 短线(恐慌择时,市场级)

- **目的**:恐慌超跌反弹择时。
- **谁选股**:不选股,宽基/全市场等权(≈ 宽基 ETF)。
- **信号**:regime == 恐慌 → 触发「超跌反弹窗口」。
- **输出**:顶部 regime-bar(已存在)在恐慌时显示建议:`action=buy_dip`;message 更新为含"持有 2-3 天"(T+1 开盘买,T+3/T+4 开盘卖)与诚实标注。非恐慌态维持现状(buy_dip/avoid/neutral)。
- **实现**:更新 `environment.py` 的 `REGIME_ADVICE["恐慌"]["message"]`;前端 `regimeLine` 已自动渲染 message,无需改前端。加测试钉住新文案。
- **诚实标注**:message 内注明"41 天样本、肥左尾(接飞刀)、非稳赚"。
- **回测依据**:`_analysis/regime_blind_test.py`(日级净胜率 66%→73%,p=0.0275)+ `_analysis/panic_persist_probe.py`(T+3 延续)。
- **不做**:不选个股、不细分恐慌、不设止损线。

## Board 2 — 波段(用户自选 + regime 启发式)

- **目的**:用户自己的股票清单 + 市场级择时指引。
- **谁选股**:**用户**(沿用自选 footer + localStorage `stock_wl`;算法不选)。
- **信号(启发式,市场级,非 per-stock)**:regime 驱动的整体指引,新增纯函数 `regime_swing_action(label)`:
  - 恐慌 → `opportunity`(等机会:超跌反弹窗口);
  - 高潮/退潮 → `exit`(卖出/回避);
  - 牛/熊/震荡/恢复 → `hold`(持有);
  - None/未知 → `unknown`。
  标注为启发式(未回测为退出信号)。
- **交互**:新增「波段」tab(左栏,与现有 tabs 平级),显示自选清单 + 上述 regime 指引 + **「切换股票」按钮**。按下按钮进入编辑态(增删自选股),其余时间只显示"今天整体:持有/卖出/等待"。
- **持久化**:自选清单沿用 localStorage `stock_wl`(不新增后端存储)。
- **诚实标注**:面板顶部明确"择时指引为启发式(regime 仅在进场/回避上验证过,非退出信号);自选股本身无算法 edge"。
- **不做**:不给自选股打算法分、不加止损线(证伪)、不算法推荐替换股、不做 per-stock 择时。

## Board 3 — 长线(定性研究,仅参考)

- **目的**:数月维度的基本面/产业逻辑判断,仅供用户自己决策参考。
- **谁选股**:我提候选(产业逻辑),纯定性。
- **方法**:web 检索(新闻、产业报告)+ 上下游供应链逻辑 + 业务基本面 → 产出论述,结构固定为:{产业逻辑 → 催化 → 风险 → 逻辑哪里会断}。
- **输出**:独立参考文档(非 app 代码主线;不挂进推荐页,不显示"荐股")。
- **诚实标注**:高不确定、非回测、仅供参考;不做伪精确分数;警惕幸存者偏差/事后偏见/幻觉。
- **不做**:不进推荐页、不打分、不承诺"必涨"。

## 实现范围与顺序

1. **短线**:改 `environment.py` 的 `REGIME_ADVICE["恐慌"]["message"]`(+ 测试钉值)。风险最低、纯后端,先做。
2. **波段**:后端加 `environment.regime_swing_action(label)` 纯函数(+ 测试);前端新增「波段」tab(自选 + regime 指引 + 切换按钮),复用 `stock_wl` 与 `state.regime`。中。
3. **长线**:非代码;on-demand 研究流程(用户要求时产出一篇参考论述)。最后/按需。

## 明确不做(YAGNI / 已证伪)

- 算法选波段股 / 长线股(选股 edge 证伪)。
- per-stock 止损/止盈线(`trade-sim-risk-stop-falsified` 证伪)。
- 恐慌细分(过拟合)。
- regime 作为"退出信号"的正式声明(未回测)。
- 长线伪精确评分。
- 波段 per-stock 择时(无 per-stock 信号)。
