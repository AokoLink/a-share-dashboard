## 1. 背景与问题

现有个股评分(analysis.py)对用户「买龙头、持 3-5 天」的策略把关,但存在系统性缺陷:

1. **区分度差**:趋势分只有 40/70/90/100 四档、量价分 40/70 两档,大量股票挤在 90-100,「刚金叉弱多头」与「均线充分发散」同分。
2. **维度缺位**:复盘(2026-08-12)发现的「低位启动、板块共振、量能持续」等大涨共性,评分一个都没用上。
3. **综合分与实操割裂**:风险只当 verdict 硬门槛、不进综合分,风险 0 和 65 同分;出现「95 分却规避」的哈药股份式反例。
4. **方向性错误**(回测证据,见 §2):v1 重奖趋势/信号与「创 20 日新高」类突破,而它们在 5 日口径下是负向因子——「已涨的」被排到最高分(十分位顶档不是最优),等于引导追高。

## 2. 回测校准证据

数据:37 个已映射板块成分股并集 1769 只,新浪前复权日线,全年滚动评估
(每只取近 300 根、每 5 根一个评估点、后续 5 日真实涨幅;N=53,537,覆盖 1623 只)。

**因子级 spearman(与后续 5 日涨幅):**

| 因子 | spearman | 解读 |
|---|---|---|
| 位置 position | **+0.0748** | 最强且方向正确(引擎) |
| 信号 signal(改造后) | **+0.0422** | 由 v1 旧口径负值**转正**(低位金叉/超卖/门控突破是主因) |
| 趋势结构 trend | −0.0224 | 仍为负:MA 排列越强 → 后续 5 日略差(均值回归) |
| 量价 vp | −0.0027 | 约等于零:单因子无预测力 |
| 风险 risk | −0.0302 | 负向:风险越高后续越差(保护性,方向正确) |

**量能持续(volr=a5/b20)实证(第二轮#1):**

- volr 与 fwd5 spearman = **−0.0061**(≈0,单看无预测力;该分项定位是「量能健康度」而非 alpha)。
- 分桶 fwd5 均值:<0.7 → −0.106;0.7~1.0 → −0.193;1.0~1.5 → **+0.059(最高)**;≥1.5 → −0.053。
- 结论:甜区 1.0~1.5 实证最优、≥1.5 回落——「温和持续放量 > 过热天量」成立,§4.2 保留甜区并改升序呈现;与复盘「主升段持续放量」不冲突(持续放量 = 区间中枢温和抬升,非单日天量)。
- **档位排序与实证桶序的关系(第三轮#2)**:实证桶均值序为 1.0~1.5(+0.059)> ≥1.5(−0.053)>
  <0.7(−0.106)> 0.7~1.0(−0.193)。但**只有「甜区 1.0~1.5 最高、≥1.5 回落」被用作甜区依据**;
  三个负向桶的相互排序按**量能健康逻辑**而非桶均值:0.7~1.0「常态略缩量」给次高分、≥1.5
  「过热天量」给中低分、<0.7「明显缩量」给低分。理由:volr spearman −0.006、负向三桶均值差
  在噪声水平,逐桶按均值排序=拟合噪声;该分项定位是「量能健康度」而非 alpha。
- spike_v3b 与文档公式一致:该分项在脚本中即 `12 if r>=1.5 else 30 if r>=1 else 20 if r>=0.7 else 6`,本文 §4.2 仅改写为升序便于阅读,数值不变。

- **探索性单窗口(仅供方向提示,不参与参数)**:2026-07 上旬→08-12,163 只深复权子样本

## 3. 设计决策

| 决策点 | 决定 | 理由 |
|---|---|---|
| 改造路线 | 方案 B 全面重构 | 用户选定;v1 方向性错误需重做,非调参可解 |
| 综合分结构 | **质量分 × max(0, 1−风险/100)** | 乘法折扣让风险直接压低分数,消除「95 分却规避」 |
| 主因素权重 | **位置 55 / 量价 15 / 趋势结构 10 / 信号 20** | §2 变体对比实测 v9 最优(spearman 与单调性双高),与因子证据对齐 |
| 风险 | 累加 cap 100;乖离门槛**梯度平滑**(消除 15% 断崖) | 见 §4.5;平滑后无相邻日跳变 |
| 板块共振 | 进综合分,**加成在风险折扣之前**(比例化) | 强势板块对临界股推一把、对垃圾股加成被风险折扣,见 §5 |
| verdict | 五档:强烈关注/关注/持有跟踪/观望/回避;初值 63/58/48/38 | 用户选定;由编排层唯一计算(§4.6),最终在含板块共振的 final_composite 上复核(§9.5) |
| verdict 作用域 | **`score_stock` 不返回 verdict**;verdict 由编排层对 final_composite 唯一计算 | 第二轮#2:避免 provisional verdict 被误当最终值 |
| 数据守卫 | `score_stock` 要求 ≥61 根,不足返回安全值 | 新因子需要更多历史,见 §4.0 |
| 参数校准 | 真实数据回测校准 | 用户选定;校准任务:单调性/因子级/风险项/板块阈值/verdict 阈值五件套(§9) |

## 4. 评分模型 v3(纯函数,analysis.py)

### 4.0 输入守卫(新增)

- `score_stock(daily_df, quote, now)`:**
  - `len(daily_df) < 61` → 直接返回
    `{"position": None, "trend": None, "volume_price": None, "signal": None,
      "risk": None, "composite": None}`(不含 verdict,见 §4.6)。
  - 61 的由来:位置需 60 根区间 + 平台需 `close[-11]`、趋势需 MA60、量价需 25、信号需
    MACD(26)+突破(21)+RSI(16)、回撤需 21——61 是覆盖全部子项的最小根数。
  - 调用方:recommend 候选打分跳过 `composite is None` 的股票(不进可介入);
    `/api/stock` 返回 `composite: null`、`verdict: null`、`tier: null`,前端显示
    **「数据不足(历史 <3 个月)」**专用标签而非空白或「观望」(第三轮#5)——短历史股无分数,
    显示「观望」会误导为「低分」,纯空白会像 bug。
- 内部除零守卫:MA20 为 0/NaN → `bias = 0`;量比基准缺失 → `vr = None`(量价分项取低分档);
  RSI 根数不足 → 跳过 RSI 子项(≥61 根时不会发生,防御保留)。
- 实时盘中量比:`vr` 经 `custom_volume_ratio(volume, trading_minutes_elapsed(now), avg5)`
  按已交易分钟折算;**收盘后(elapsed=240)与校准口径(完整日线自然量比)完全一致**。

### 4.1 位置 position(权重 55%,自然上限 89.5)

```
pos60 = (close − min(low[-60:])) / (max(high[-60:]) − min(low[-60:]))   # 分母≤0 → 0.5
pos_factor = 100 × (1 − pos60)                                          # 低位置高分
bias = (close − MA20) / MA20 × 100                                      # MA20≤0 → 0
bias_sweet(乖离甜区):
  bias < −8          → 0
  −8 ≤ bias < −3     → 15
  −3 ≤ bias < 0      → 35
  0 ≤ bias ≤ 3       → 35 + 65 × min(1, bias/3)         # 0→35 连续(消除 bias=0 台阶),3%→100 甜区峰值
  3 < bias ≤ 8       → 100 − (bias−3) × 12              # 3~8% 线性衰减(甜区约 2~4%,峰值在 3%)
  8 < bias ≤ 15      → 40 − (bias−8) × 4               # 8%→40 分,15%→12 分
  15 < bias ≤ 20     → 12 − (bias−15) × 1.4            # 15%→12 分 → 20%→5 分,线性
  bias > 20          → 5
platform(近 10 日振幅):amp=(max(high[-10:])−min(low[-10:]))/close[-11]×100
  amp ≤ 8 → 30; 8<amp≤15 → 15; amp>15 → 0
position = min(100, 0.5×pos_factor + 0.35×bias_sweet + 0.15×platform)   # 自然上限 89.5
```

- **方向张力说明(有意为之)**:`pos_factor` 奖励「低 60 日位置」(深跌后),`bias_sweet`
  奖励「刚站上 MA20 并在甜区温和抬升(0~3%,峰值 3%)」。两者方向部分相反——这是刻意的:
  分别捕捉「空间」(还能跌多少)与「启动状态」(刚转强)。组合对「低位刚启动」最优;深跌中
  (低 pos60 且 bias<0)只拿 pos_factor,不给转强加分。
- **甜区与台阶(第三轮#1)**:甜区峰值在 bias=3%(0~3% 由 35 线性升至 100,3~8% 线性衰减,
  甜区约 2~4%),不是平台也不是单点;bias=0 与 bias=15 两处台阶均已消除——bias 由 −0.01→+0.01
  bias_sweet 不再跳 35→100(原约合 12.5 综合分)。**残留小台阶**:−8(0→15)与 −3(15→35)仍是
  离散步,各约合综合分 2.9/3.85,均小于一个 verdict 档位宽(5),不足以单独跨档;保留以维持
  「深跌折扣/常态/转强」三档语义。spike_v3b 已按此公式重跑(run 4)验证 spearman。

### 4.2 量价 volume_price(权重 15%,自然上限 100)

```
vr = 当日量 / mean(volume[-6:-1])(实时经 §4.0 折算)
分项一(量比健康度):vr≤1.5 → +35; 1.5<vr≤2.5 → +26; vr>2.5 → +12; vr缺失 → +12
分项二(价量一致):chg=当日涨跌幅%
  chg>1 且 vr>1.2 → +35; chg>0 且 vr<0.8 → +15; chg<−1 且 vr>1.2 → +5; 其余 → +25
分项三(量能持续,甜区,升序呈现):r = a5/b20 = mean(volume[-5:]) / mean(volume[-25:-5])
  r < 0.7            → +6      # 缩量
  0.7 ≤ r < 1.0      → +20
  1.0 ≤ r < 1.5      → +30     # 温和持续放量(甜区):实测该桶后续5日均值最高
  r ≥ 1.5            → +12     # 过热/天量:实测劣于甜区
```

- 分项三为**甜区非单调**设计,由 §2 volr 实证支撑(1.0~1.5 桶 fwd5 最高、≥1.5 回落);
  与复盘「主升段持续放量」不冲突——持续放量是区间中枢温和抬升,非单日天量。
- **三个负向桶的排序按健康逻辑(第三轮#2)**:0.7~1.0「常态略缩量」+20、≥1.5「过热」+12、
  <0.7「明显缩量」+6——并非按(噪声水平的)桶均值排;桶均值只锚定「甜区 1.0~1.5 最高、
  ≥1.5 劣于甜区」两点。详见 §2。
- volr 缺失(b20=0,近 20 日无量)→ 该分项不贡献(+0);spike 中即 `if volr is not None` 守卫。
- 数值与 spike_v3b 完全一致(该脚本即 `12 if r>=1.5 else 30 if r>=1 else 20 if r>=0.7 else 6`,
  此处仅改写为升序)。

### 4.3 趋势结构 trend(权重 10%,自然上限 55)

```
order = (MA5>MA10) + (MA10>MA20) + (MA20>MA60)          # 各 0/1
base = 40 × order/3
fresh:近 5 根内 MA5 上穿 MA10 → +15; 否则 MA5>MA10 → +8; 否则 +0
```
(不含发散度/乖离奖励——发散与乖离由位置因子负责,避免重复奖励「已涨」。
该因子单因子 spearman 为 −0.022(§2),故权重压到 10%:仅作「不逆势」的结构护栏,不给 alpha。)

### 4.4 信号 signal(权重 20%,自然上限 90)

参数:DIF = EMA12 − EMA26,DEA = EMA(DIF,9);「金叉」= 当根上穿(昨 DIF≤DEA 且 今 DIF>DEA)。

```
MACD(互斥 if-elif,优先级从高到低):
  当根金叉 且 DIF>0      → +30     # 零轴上方金叉(最强)
  当根金叉 且 DIF≤0      → +15     # 零轴下方金叉
  DIF>DEA(非当根)且 DIF>0 → +12    # 已金叉、零轴上维持
  DIF>DEA(非当根)且 DIF≤0 → +8     # 已金叉、零轴下弱多头
  其余                   → +0
RSI14:r≤65 → +25; 65<r≤80 → +12; r>80 → +5          # r<30 落入 ≤65 → 超卖修复加分
突破(低位门控):仅当 pos60 < 0.6:
  close > max(high[-21:-1]) 且 vr>1.2 → +20
  close > max(high[-21:-1])(不放量)  → +10
  否则 → +0
动量:ret5=(close/close[-6]−1)×100; 0≤ret5≤8 → +15; −3≤ret5<0 → +8; 其余 → +3
```

- **突破低位门控(第一轮#3 修复)**:旧的「close>max(high[-21:-1])」对连续上涨股每日触发
  (= 每日创 20 日新高 = 奖励已涨)。现限定 `pos60<0.6`,只在低位突破时加分。
  未采用 60 日新高窗口:它对回调后二次启动过于严苛,且低位 20 日新高已覆盖「启动突破」语义。
- **MACD 优先级(第一轮#8 修复)**:if-elif 互斥,当根优先于状态维持;零轴上方金叉(+30)严格
  高于零轴下方金叉(+15),修复「零轴下方金叉反而更高分」的反向。
- **「新鲜度优先于高度」注**:零轴下方当根金叉(+15) > 零轴上方已金叉维持(+12)——刚金叉
  比金叉久更可买,与「买低不追高」自洽,并非方向反了(第二轮#5)。
- 该因子是 v3 信号改造后 **spearman +0.0422 转正**的直接载体(§2),支撑 20% 权重。

### 4.5 风险 risk(0–100,累加 cap 100)

```
乖离(梯度平滑,消除 15%/25% 断崖):
  bias ≤ 15            → +0
  15 < bias ≤ 20       → 40 × (bias−15)/5          # 15% 处 0 → 20% 处 40,线性
  20 < bias ≤ 25       → +40
  25 < bias ≤ 30       → +40 + 30 × (bias−25)/5     # 25% 处 40 → 30% 处 70,线性
  bias > 30            → +70
放量跌破MA20:vr>1.5 且 close<MA20 且 chg<0                 → +40
放量滞涨:vr>1.5 且 chg<前日涨幅 且 chg<2                      → +25
高位长上影:上影>2×实体 且 振幅>5%                              → +20
近20日最大回撤>25%                                           → +20
cap 100
```

- **平滑性**:bias 从 15.0→15.1,乖离风险从 0 只增到 0.8(而非旧设计的 0→40 跳变);
  bias_sweet 在 0~3 与 15~20 均已线性化(§4.1),消除 bias=0(原全模型最大台阶,约 12.5 综合分)
  与 bias=15 两处台阶,综合分不再出现相邻交易日腰斩;残留小台阶 −8/−3 各约合 2.9/3.85 综合分,
  小于一个档位宽。
- 各单项幅度(40/40/25/20/20 + 乖离梯度)为**初值**,由 §9.3 校准任务按「命中组 vs 未命中组
  后续 5 日均值」逐项验证与调整。

### 4.6 综合分、verdict 与 tier(管线顺序固定;verdict 作用域,第二轮#2)

```
stock_composite_v3(position, vp, trend, signal, risk, sector_bonus=0):   # 纯函数
  quality = 0.55×position + 0.15×vp + 0.10×trend + 0.20×signal
  return (quality + sector_bonus) × max(0, 1 − risk/100)                  # 未舍入

stock_verdict(composite_raw):≥63 → 强烈关注;≥58 → 关注;≥48 → 持有/跟踪;≥38 → 观望;<38 → 回避
tier_for_verdict(v):{"强烈关注","关注"} → 可介入;{"持有/跟踪"} → 观察;其余 → None
```

- **`score_stock` 只返回因子 + `composite`(= `stock_composite_v3(..., sector_bonus=0)`,未含板块、未舍入),不返回 verdict**。
  **verdict 的唯一来源 = 编排层对 final_composite 调 `stock_verdict`**:
  ```
  编排层(recommend.py / app.py):
    final = stock_composite_v3(position, vp, trend, signal, risk, sector_bonus)
    verdict = stock_verdict(final); tier = tier_for_verdict(verdict)
    展示值 = round(final, 2)
  ```
  避免「score_stock 返回的 provisional verdict 被调用方/测试误当最终值」。
- **verdict 判定用未舍入 `composite_raw`**:避免 57.996 vs 58.004 被两次 round 推到不同档。
- **权重(55/15/10/20)**:§2 变体表实测 v9 最优(+0.0655,单调性 0.915,均 run-4)。
- **verdict 阈值(63/58/48/38)为初值**,依据 §2 当前全市场分布(v9:强烈关注 ≥63 ≈ 10%、
  可介入 ≥58 ≈ 27%,含板块加成前;实测严格 >62=11.3%、>58=28.0%,>/≥ 边界差个别重采样个股);
  **最终校准以含板块共振的 final_composite 分布**复核定档(§9.5),若可介入率偏离目标
  top 20–30% 则整组平移。

## 5. 板块共振(编排层,recommend.py)

```
给定股票已解析到的板块(可多个),取 sector composite 最高的那个:
  ≥70  → +8; 55≤x<70 → +4; x<40 → −5; 其余 → +0
sector_bonus 在风险折扣之前加入质量分(§4.6):final 加成按 (1−risk/100) 比例缩放,
  强势板块对低风险好股加成充分、对高风险垃圾股加成被风险折扣压小——修复「+8 对 12 分股
  是 +67% 救赎」的不对称。
```

- **阈值与幅度为初值**:板块 composite 来自现有 `score_all_sectors`(P1–P6 三因素模型,
  60s 缓存),其分布与个股综合分不可比。§9.4 统计板块 composite 分布后,按百分位重定阈值
  (初定 P80/P50/P30 ↔ 70/55/40)。
- **应用位置**:
  - `collect_actionable_leaders` / `build_recommend`:leader 自带 `sector_name` → 查该板块 composite。
  - `/api/stock` 个股详情:**尽力而为**——`data_source.resolve_code_sectors(code)`
    (手动映射表优先,关键词兜底,缓存 1800s)。返回 dict 带 **`sector_resolved` 布尔**:
    解析成功 → 应用加成并 `true`;失败 → 加成 0 且 `false`,前端提示「板块未解析,未含共振加成」,
    不静默 +0(修复「列表页有加成、详情页无加成导致分数不一致」)。
- 影响面:tier 判定在板块加成之后,强势板块可把 55 分股推入「可介入」,符合「板块共振」语义。
