# 第四阶段：冻结信号与前向验证

> 初版实施日：2026-09-30；已纳入第二轮 B 批次的每日任务与逐日进度更新。阶段二历史回测不能反填为前向观察；当日真实运行情况见[步骤 B 实施记录](step-b-implementation.md)。

## 每日闭环

收盘后 15:05 起运行统一每日任务；网页“策略验证”只读取已保存的结果：

```powershell
python -m pipeline.run_daily
```

当前研究池中每只股票的双价格日线须截止当日、具有足够历史，并通过与现货的价格及量额校验，才冻结当次结果。研究池输入不完整时保留错误与研究展示，不冻结。突破、回调、反弹分别保存空结果和候选结果。每条记录包含策略版本、代码哈希、参数、市场状态、当时的前 200 只股票池、执行与技术参考收盘价、板块映射、候选排名、理由、价格输入哈希、数据覆盖和来源限制。冻结版本号带有策略实现、候选生成规则和参数指纹；同版本相同内容重复执行幂等，内容变化增加修订记录，不覆盖首次快照。冻结表位于 `data/market.db` 的 `strategy_signal_snapshot`，可用 `/api/strategy-snapshot/<id>` 复核全文。

每日任务自动更新跟踪；也可以仅使用已保存价格更新进度：

```powershell
python pipeline/track_strategy_signals.py
```

后台跟踪读取 `_analysis/daily_pipeline/execution/raw_daily/` 中具有 SHA256 元数据的未复权价格；每日任务不以旧 pkl 填补缺失执行价格。独立跟踪命令仍可显式指定旧数据路径，但会标记未核实的价格口径。新信号使用留档前复权价格筛选，同时冻结未复权执行参考收盘价；跟踪前仍必须校验 T 日收盘与冻结值在 0.5% 内，否则不模拟成交。T 日收盘产生信号，T+1 开盘模拟买入；向上跳空超过 5% 则取消，不补单。趋势突破在 T+6、强势回调在 T+11、超跌反弹在 T+4 开盘退出，每边模拟 0.1% 费用及 0.1% 滑点。跟踪版本 `forward-observation-v3` 在 T+1 即写入入场或取消状态，持有期内记录进度，退出后才计算最终收益。策略与同池／板块对照分别保存毛、净收益；`filled_share_of_pool` 表示已模拟入场股票数占池规模，不称账户换手。

归因以冻结时的同日池和板块归属为准，分成池内等权市场、板块选择、个股选择及执行成本；无实际仓位时“仓位调整”为空。板块关系为当时捕获的当前来源，不证明历史成分；日开盘也不证明真实可成交，停牌、涨跌停状态和公司行为尚未验证。尚未到入场／退出时点、缺失价格和日历未覆盖分别保留原因，不填造收益。收盘行情或新股排除来源失败后不写入新鲜快照。已完成观察默认保留，必要时用独立跟踪命令的 `--recompute` 另存重算。

`GET /api/strategy-monitor` 返回每个策略版本的冻结日、修订、有效前向观察、独立事件簇、数据失败、板块覆盖、平均候选分、成本后超额与状态事件。`?date=YYYY-MM-DD` 可筛选快照；详细快照仍用 ID 查询。报告另存于 `_analysis/stage4_strategy_monitor.json`。

## 版本状态与门槛

状态事件追加保存，可人工暂停、降级或退役版本。暂停、退役版本不进入正常候选或新增模拟建仓；暂停版本可在命令行加 `--shadow` 或接口加 `?shadow=1` 显式查看仅观察候选，结果不冻结。信号冻结后到次日开盘前暂停会取消新入场；已经入场的信号继续保留原观察和退出路径。示例：

```powershell
python pipeline/set_strategy_status.py --strategy breakout --version "stage2-technical-v1+0123456789ab" --status paused --reason "数据源连续异常，待复核"
```

示例中的指纹需替换为监控页实际版本号。允许的路径为探索研究 → 历史验证 → 前向观察 → 正式使用；各阶段可暂停或退役，暂停后可带理由返回早期状态。正式使用必须经过至少 60 个完整前向观察日、30 个独立事件簇、成本后对市场和板块均为正的证据门槛，且数据质量问题解除。当前历史成分、公司行为和执行状态未获可信覆盖，系统会持续阻止升为正式使用。状态变更需要人工记录理由，不随一次收益波动自动晋级或退役。

目前可以完成冻结、模拟和审计，但还不能断言策略有效或适合交易。后续需持续采集新鲜日线、补齐停牌与涨跌停核查、公司行为及历史板块成分，按独立事件而非重复信号重新评估低频反弹策略。

第二轮步骤 E 已另建现金股数账户，日常跟踪后核算账户净值、资金换手、公司行为与重叠持仓。此处逐股观察仍保留原口径，不能当作账户收益；新账户的输入与剩余门槛见 [步骤 E 实施记录](step-e-implementation.md)。
