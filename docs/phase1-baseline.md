## 已实施

| 范围 | 修正后的口径 |
| --- | --- |
| 细分行业 | 半导体等七个细分行业不再共用新浪“电子信息”或“电子器件”成分池；仅在东财存在同名行业时取其成分，并显式标为跨来源匹配；否则返回 `coverage_insufficient`。新浪宽行业映射保留并声明来源与非历史属性。 |
| 股票池 | 离线股票不再因“截至今天不足 1200 根”被全程剔除，只需至少 61 根历史。评估日候选资格不依赖次日行情是否存在；未来行情只产生结果标签。 |
| 主题动量 | 不同股价先按同一初始资金归一化，再计算主题价格序列；不再直接平均 10 元与 100 元的报价。 |
| 主题仓位回测 | 收盘产生信号，下一交易日开盘按逐股目标资金权重买卖；按股数、现金和实际换手额扣成本；每个交易日收盘估值。缺失开盘价时不虚构成交。数据最后一天不再自动视作月末。 |
| 旧主题策略时间轴 | 信号日净值在处理下一日交易之前锁定，期末估值单列；下一日开盘变化不再反写前一日净值。该旧策略仍使用合成主题指数，列为探索性研究。 |
| 旧交易模拟 | T 收盘后生成信号、T+1 开盘买入；T+1 当日不可卖出，最早 T+2 交易。旧 `close[T]` 入场口径已废弃。 |
| 预测校准 | 多周期诊断对每个 1/3/5/10/20 日收益标签，按 `T+1+h` 的结束日清除跨越训练/验证边界的训练样本；旧预测管线的 T+1 与 T+3 标签也分别隔离。 |
| 新鲜度 | 离线市场环境过期时保留历史标签，撤销其当前操作建议；推荐信号按行情截止日标为当前或历史；主题旧报告和过期报告只在历史字段展示，不再输出当前仓位。持仓诊断分别判断行情截止日、校准器生成日及模型版本，旧校准结果只作历史研究展示。 |

## 数据核查

- `_analysis/daily` 有 1,641 个股票日线文件，`_analysis/code2sector.json` 有 1,799 个代码。四个日线文件少于 1,200 根，现可在满足历史窗口时参与。1,639 个日线结束于 2026-08-14，其余分别结束于 2026-08-12、2026-08-10。
- 离线日线共同字段为 `date/open/high/low/close/volume/amount/outstanding_share/turnover`。在线 `get_stock_daily` 明确调用东财 `adjust="qfq"`；仓库没有对每份离线 pkl 的复权来源做逐文件证明，因此交易账本的逐股价格仍标记为“复权状态未验证”。
- 在线日线规范：成交量为股、成交额为元、换手率为小数。交易模拟要达到真实现金流口径，还需未复权成交价与分红送转事件；前复权价格可供技术指标研究，不宜直接当作可成交价格。
- 静态 `code2sector.json` 没有成分生效/失效日期；现有日线没有历史 ST、停牌、涨跌停可成交性与退市股票覆盖证明。东财同名行业也仅是当前跨来源近似，不能回填到历史日期。
- 新鲜度计算已优先读取保存的交易日历并标明 `calendar_basis=akshare_sina`；日历未采集时才退回工作日代理。日历范围外返回 unknown，不推断为“当前”。

## 修正后的探索性重算

`pipeline/theme_vol_strategy.py` 已用当前离线数据重算 `_analysis/theme_vol_strategy.json`：数据截至 2026-08-14，最后一个已确认月末信号为 2026-07-31。重算产物记录 `input_sha256`、`code_sha256`、`accounting_version=shares-cash-v1` 与 `price_basis=daily_pkl_unverified_adjustment`。

当前重算的 vol-target top2 净值约 20.745、回撤约 -38.54%；满仓 top2 净值约 26.600、回撤约 -39.62%。这些数字仅用于核对新代码的输出，不用于判断策略收益：固定核心组和静态板块/股票池存在历史选择偏差，价格口径与公司行为尚未核实，输入也已过期。旧主题仓位净值、旧交易模拟与旧多周期校准结果均应停止作为策略证据；生产推荐重建、波段盲测及低位恐慌报告可保留为带代理限制的探索性证据。

## 进入正式基线前仍需的数据

1. 可按日期查询的行业、细分行业、概念成分变更记录，至少含代码、类别、来源、生效与失效日期；历史缺口要逐期标注。
2. 含退市股票的历史行情、上市日、历史 ST、停牌与真实可成交涨跌停状态；按当时的信息构造股票池，并量化当前数据集的幸存者偏差。
3. 交易使用的未复权 OHLC 与分红送转事件，以及经过核实的成交量、成交额、换手率字段说明；将技术指标的复权价格与交易现金流分开。
4. 已保存的日历需持续更新；其他旧数据集仍需采集时间、行情截止时间、模型训练截止时间。
5. 补齐上述输入后，重新运行主题回测、旧交易模拟与多周期校准，并在报告中保存数据哈希、代码哈希、参数、时间窗口和成本。结果好坏如实保留，再决定是否升级为正式基线。

## 已验证的第一批不变量

- 两只股票分别由 10→11 元、100→100 元时，等初始资金主题收益为 5%。
- 改动执行日开盘价不改变信号日及以前净值；成交日的股数、现金与成本可相加核对。
- 旧模拟不允许 T+1 买入当天卖出；多周期训练样本的标签结束日早于验证起点。
- 缺失精确成分、过期数据及未验证价格口径在 API 中明确降级。
