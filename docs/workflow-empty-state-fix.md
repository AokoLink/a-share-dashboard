# 市场环境与策略候选空白修复

实施日期：2026-10-08。

## 原因

市场环境主面板原先只有流程说明，数据只在顶部横条；缺少标签或接口失败时横条被隐藏，用户看不到缺口。旧 `/api/regime` 还会从 `_analysis/daily` 的历史 pkl 重算并写入每日任务同名缓存，使旧历史状态覆盖新版状态。

策略候选接口在 15:05 前正确返回 `waiting_for_close` 及空的今日列表，但页面没有专门解释等待状态；无结果时表格也被清空。重启应用不会自动运行后台每日任务，因而不会产生新候选。

## 修复

- 市场环境主面板直接显示数据截止、分类状态、已积累／所需交易日及环境指标。没有记录、没有标签或读取失败均显示原因，不隐藏。
- 新增只读 `/api/market-environment`，按数据日期选择最近的后台环境留档，从运行清单提取引用并验证 SHA256。未来日期不参与选择，无留档返回 `not_run`；损坏或引用不符返回错误，不从旧历史状态补造当前状态。
- 同时展示该日期保存的单日市场记录，标注为描述数据；单日涨幅中位数、上涨占比、涨跌停家数与成交额不能替代多日环境分类。环境原报告的空指标不被填成已分类数据。
- 旧 `/api/regime` 保留兼容，其计算缓存改为 `regime_cache.json.legacy.json`，不再覆盖每日环境缓存。
- 策略候选显示“等待 15:05 后的后台任务”“尚未运行”“没有入选”“策略暂停”或读取失败。策略说明卡在没有候选时也可见。
- 收盘前默认列表仍为空，不新增或冻结候选；返回上次留档日期和数量，并提供显式历史入口 `/api/strategy-candidates?history=1`。历史结果标注截止日、未封印原因及非今日信号，`actionable=false`，不写入前向表。
