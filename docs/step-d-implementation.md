# 步骤 D：共享筛选引擎与登记实验

> 实施日：2026-09-30。对应[第二轮方案 D1—D3](project-improvement-plan-v2.md)。共享流程、实验登记、同日对照和研究报告已实施；历史来源缺口和未参与设计的前向验证仍未通过。

## D1：在线和历史共用完整决定

新增 `core/screening_engine.py`，供后台生成、历史评估和留档重放共用：

**按 T 日截断数据 → 基础资格及字段校验 → 成交额排序并截断股票池 → 同日环境／板块条件 → 策略触发 → 策略内排序 → 后台冻结。**

最多 200 只的股票池在历史资格确认之后形成；策略最多 20 只。成交额降序、六位代码升序是统一的并列规则。无当日收盘、缺字段、无效历史、ST、流动性不足、涨停代理、历史不足等原因逐代码保存。未知历史名称不能使用未来名称替代，仍标记历史 ST 未核实。

每日采集先排除无需历史即可确认的新股名单、ST 和不足 1 亿元成交额股票，**不先截断为 200 只**。之后为整个待资格范围更新价格，再由共享引擎选出资格后池。日报将待资格范围 `qualification_inputs` 与资格后 `research` 分开；对照及已有持仓／候选仍保留采集。资格未知时阻止把局部池冻结为完整新信号。新版所需价格范围比 B 批次固定 200 只扩大，首次完整运行需要补齐范围内日线，可继续使用 B 的逐代码 checkpoint 和断点恢复。

后台保存完整 `screening_decision`：资格结果、池及排名、策略排序、理由、板块证据、参数和决定哈希。入场与退出结果在另一模块计算，未来开盘不进入决定。筛选身份升级为 `shared-daily-screen-v5`，规则标识为 `stage2-technical-v2-experiments`；旧版本冻结及观察不覆盖。

留档一致性验证命令：

```powershell
python -m pipeline.audit_screening --run-id <每日运行编号>
```

命令实际经过后台生成和历史评估两个入口，输出资格、池、排序及理由差异；另将未来价格改为极端值并比较 T 日决定。它不采集、冻结或计入前向样本。

真实留档重放 `9c10ebea-7a4d-46c4-b172-f23113b2beef` 使用 B 原运行 `36078f24-d847-4c92-995b-ee67d17f8294`：两个入口的决定完全一致，未来数据修改后也一致。扩大后的待资格范围为 **2468 只**，旧留档只有 **194 只**当日技术输入可进入资格池，另 **2274 只**缺输入。这里证明的是相同可用输入下的一致性，不能称为完整市场覆盖；报告保存全部缺失代码，重放未冻结信号。见[一致性报告](../_analysis/daily_pipeline/screening_audits/9c10ebea-7a4d-46c4-b172-f23113b2beef/report.json)。

## D2：逐项条件实验及完整事件核算

新增 `pipeline/strategy_experiments.py` 与 `core/research_evaluation.py`，默认规则加七个逐项移除条件的变体，详见[实验登记说明](strategy-experiments.md)。变体只用于研究，不接入正常每日候选。

所有臂在同一 T 日资格池上产生，采用同一持有期、跳空限制、费用和滑点。对照包括同池等权、同板块等权、T 日板块内随机名单、上证综指参考代理，以及回调与同日突破按同一回调持有期的对照。板块或指数来源缺失时明确留空。原 `pipeline.evaluate_strategies` 接入此框架，默认输出新 v4 文件，旧报告保留。

保留每条入选事件、取消、缺入场价格、缺退出价格、日历未覆盖及未到期状态。同时报告：

- **已成交条件下收益**：仅解释已完成交易样本，展示其数量，不表示所有原入选股票的收益。
- **固定份额研究代理收益**：按 T 日等权份额计算；明确跳空取消的份额留现金，未知行情不作零收益，也不重分配给后来完成交易的股票。任一所需事件未知时该臂留空。
- **账户收益**：当前留空，需步骤 E 的现金、股数、重叠资金与公司行为账本。

板块随机名单在检查未来成交／退出行情之前抽取，避免幸存成交偏差。策略与基准同时保留毛、净收益，同口径净超额；入选集合与同池完全相同时净超额为零。

## D3：登记、隔离与研究评审

实验在读取历史和核算收益前登记，登记文件不可覆盖，保存假设、股票池、参数、持有期、成本、对照、主要指标、停止条件和核心代码哈希。所有研究结果引用对应登记文件。逐日决定、原始事件、变体和负结果全部保存。

当前已使用的历史明确归为“曾查看的开发区间”。前向验证起点设为 **2026-10-01**；当前没有未来样本，独立验证行数为 0。框架按收益标签结束日隔离，设 10 个交易日缓冲，支持扩展开发区间后逐月验证；跨月未结束标签单独保留。

相邻／重叠收益标签合并事件簇，报告事件簇等权超额、有效簇数与描述性自助抽样区间；按市场环境分组，保留成交额和 20 日波动风格差异。成本检验 0、0.5、1、1.5、2 倍既定每边费用／滑点。市值历史和历史交易状态仍不能解释，数量达到门槛或均值为正不会自动升级策略。

独立评审 `pipeline.review_strategy_experiment` 不修改主实验结果。若历史板块特征覆盖为 0，则去板块条件的零差异标为 `blocked_feature_coverage`，不解释为板块强度无效。
