# A 股分析项目：现状评估与四阶段改进方案

> 整理日期：2026-09-29。本文是基于仓库代码及已有研究报告的改进规划，不代表已实施的改动，也不构成具体股票的交易建议。

## 一、总体判断

项目已有行情看板、板块与个股评分、推荐、市场环境分类、离线回测、预测校准、交易模拟和复盘等模块。数据、分析与 Web 层已拆分，研究报告也记录了部分失败实验，具备继续研究的基础。

当前最主要的缺口是：板块分类与选股池不够精确，部分回测计算及时间口径需要修正，已有的高分推荐尚未证明稳定的成本后超额收益。改进应按以下顺序进行：

1. 建立可信的数据和回测基线。
2. 将选股拆分为目标和持有周期明确的独立策略。
3. 增强板块、龙头及组合层的分析。
4. 持续冻结信号、验证效果并决定策略的保留或淘汰。

每一阶段以可复核的交付物和验收结果为准。新增指标数量和页面数量不应作为进度的主要依据。

## 二、现状与优先处理的问题

| 优先级 | 发现 | 影响与处理方向 | 依据 |
| --- | --- | --- | --- |
| P0 | 半导体、消费电子、通信设备、计算机设备、软件开发等细分行业共用新浪“电子信息”成分池 | 板块名称不同，实际选股池却高度重叠；先纠正成分关系或标明覆盖不足 | [`core/data_source.py`](../core/data_source.py) |
| P0 | 主题策略直接平均不同股票的价格，却把结果描述为等权主题收益 | 高价股在组合计算中占更大比重；需按资金权重和持仓数量核算 | [`pipeline/theme_strategy.py`](../pipeline/theme_strategy.py) |
| P0 | 主题策略使用下一交易日开盘价建仓后，又以该持仓计算信号日净值 | 历史净值和最大回撤存在时间错位；需分离信号、执行和估值时点 | [`pipeline/theme_vol_strategy.py`](../pipeline/theme_vol_strategy.py) |
| P0 | 多周期预测按信号日切分训练和验证，没有按收益标签结束日清除跨边界样本 | 长周期训练标签可能包含验证期行情；需按各预测周期设置隔离带 | [`core/forward.py`](../core/forward.py) |
| P0 | 离线市场环境、主题仓位与在线行情缺少统一的新鲜度检查 | 旧信号可能继续作为当前建议展示；需统一时间戳和过期状态 | [`web/routes/recommend.py`](../web/routes/recommend.py)、[`web/routes/theme_vol.py`](../web/routes/theme_vol.py) |
| P1 | 板块评分中的涨停占比目前始终传入空值 | 设计中的板块情绪信息未真正使用；应计算该指标或明确删除该因子 | [`core/analysis.py`](../core/analysis.py) |
| P1 | “龙头”主要由成交额前三与当日涨幅前三合并得到 | 当前标签更接近“成交活跃/当日领涨”；应区分成交核心、价格领涨和产业核心 | [`core/recommend.py`](../core/recommend.py) |
| P1 | 部分旧交易模拟用信号日收盘价作为入场价 | 若信号依赖完整收盘数据，该价格不可直接作为之后的成交价；需统一可执行交易时序 | [`pipeline/simulate.py`](../pipeline/simulate.py) |

针对主题回测做过两个最小数值复核：两只股票分别从 10 元涨到 11 元、100 元保持不变，等资金配置收益应为 5%，当前直接平均价格得到约 0.91%；只改变下一交易日开盘价，前一日净值便可由 0.998 变为 0.499。这两个例子说明先修核算与时间轴的必要性。

现有研究对选股能力也给出了约束：

- [生产口径板块重建报告](../_analysis/prod_composite_rebuild.md)中，推荐篮子的可执行次日开盘至再下一日开盘平均收益为 -0.141%，全市场篮子为 +0.054%。两者评估日不完全一致，重建仍含代理差异；结论是“未证明增量价值”，不能据此断言未来一定无效。
- [波段盲测报告](../_analysis/swing_blind_test.md)中，`N=5` 口径的波段候选平均收益为 -0.109%，全市场为 +0.282%。高换手和高振幅可用于描述活跃度，尚不能直接用作收益信号。
- [低位与恐慌条件检验](../_analysis/lowpos_panic_probe.md)未证明低位组在恐慌日优于等权市场。低位透视适合先作为观察工具。
- 已有[历史日线报告](../README.md)与较新的数据内容存在口径差异。抽查的股票日线包含 `amount`，但部分旧报告仍声明缺少该列；报告和数据版本需统一记录。

抽查时，若干股票日线与市场环境缓存截至 2026-08-14，主题策略最近信号为 2026-07-31。相对于本文整理日期，这些离线产物已滞后，应显示为历史研究结果。

## 三、第一阶段：修复数据与回测基础，建立可信基线

**实施进度：**已完成第一批计算和展示修复；历史成分、退市/历史 ST、未复权价格与交易日历等源数据仍缺失，正式基线尚未验收。详见[第一阶段实施与基线状态](phase1-baseline.md)。

**目标：**确保板块归属、收益、净值、样本外表现及数据时间能够复核。该阶段冻结现有评分参数，便于区分“计算修复”与“策略调整”的影响。

| 工作方向 | 改进策略与方案 | 交付物 |
| --- | --- | --- |
| 板块分类 | 分别维护行业、细分行业、概念题材；取消把多个细分行业默认当成同一成分池。映射不能确认时显示覆盖不足 | 板块分类表、成分来源与映射质量报告 |
| 历史成分 | 为股票与板块关系记录来源、生效日期、失效日期。历史关系缺失时，报告标注近似程度 | 按历史日期查询的成分关系 |
| 时间规范 | 记录行情时间、采集时间、信号生成时间、执行时间和模型训练截止时间；按交易日历判断是否过期 | 统一时间字段与新鲜度规范 |
| 行情口径 | 统一成交量、成交额、换手率单位；明确复权价格用于技术计算的规则，以及交易模拟中原始价格、股数、分红送转的处理方式 | 数据字段与价格口径说明 |
| 组合核算 | 明确等资金、等股数、市值加权的差异；主题策略按资金权重及实际持仓数量计算净值 | 可逐笔核对的组合核算口径 |
| 交易时序 | 分离信号生成、下单、成交、持仓更新和净值估值；未来成交不得改变过去净值 | 统一回测时间轴 |
| 训练验证隔离 | 按标签结束日期清除跨越训练与验证边界的样本；1/3/5/10/20 日分别确定隔离范围 | 无边界污染的验证规范 |
| 历史股票池 | 按当时的上市、ST、停牌、涨跌停状态筛选；逐步补充退市股，量化幸存者偏差 | 股票池覆盖报告 |

数据过期时，行情和历史报告可以继续查看，但“当前建议”应降级为“历史信号”。模型是否过期单独判断，不能只看行情更新时间。

修复后重新分级旧研究结果：计算正确且可复现的结果作为正式基线；存在代理和历史缺口的结果作为探索性证据；存在净值错位、收益核算错误或验证污染的结果重新生成，旧数值停止用于策略判断。

**验收条件：**

- 改动未来行情不会改变任何过去的信号或净值。
- 简单人工组合的收益、现金、持仓和成本可以逐笔核对。
- 板块覆盖不足与数据过期能被明确识别。
- 相同数据、参数和代码版本可复现同一结果。
- 产出修正后的基线报告；结果变差也如实保留。

## 四、第二阶段：重构选股体系，形成独立、可比较的策略

**实施进度：**已实现三套技术策略的共享筛选定义、在线研究候选与同日对照评估；中期配置因缺披露时点历史暂不生成候选。历史板块强度和交易状态仍不足，结果只作探索研究。详见[第二阶段实施与对照结果](phase2-strategy.md)。

**目标：**让每只股票的入选理由、适用环境、执行时点和持有期限清楚可查。将选股拆成“基础资格 → 策略条件 → 策略内排序 → 风险与交易约束”。基础资格可共用；不同策略的信号和退出方式独立。

| 研究策略 | 核心假设 | 候选与排序方案 | 重点验证 |
| --- | --- | --- | --- |
| 趋势突破 | 强势板块中的有效突破可能延续 | 板块相对强度、平台突破、成交参与、个股相对板块强度；允许高位股票作为候选接受检验 | 假突破率、跳空后的收益、成本后超额 |
| 强势回调 | 已形成趋势的股票在有序回调后可能恢复 | 中期趋势、回调深度、缩量程度、关键结构保持情况 | 与直接追涨相比，是否改善收益和回撤 |
| 超跌反弹 | 特定市场压力状态可能伴随短期修复 | 市场状态先行，低位与超跌作为附加条件；强化流动性及尾部风险检查 | 选个股是否优于直接持有宽基或等权篮子 |
| 中期配置 | 基本面改善与合理价格可能形成中期机会 | 盈利质量、现金流、负债、估值和行业景气；严格按财报实际披露日期使用数据 | 是否提供独立于价格动量的增量信息 |

中期配置依赖新增基本面数据，可在前三类稳定后推进。上述均为待检验假设，不是已确认有效的策略。

每个策略使用固定说明卡，至少记录适用市场与股票范围、入选条件、排序依据、最早可执行时间、取消交易条件、持有周期、退出规则、风险约束和证据状态。一个股票出现在多个策略中时，分别解释原因。

新因子按增量价值评价：对比加入前后的表现，并在独立时间区间检查稳定性。现有统一综合分可继续作为分析字段，但突破、回调、反弹不宜强行共用同一权重和同一高位过滤门槛。

板块选择与个股选择分别测量，至少建立以下同日、同池、同成本对照：

| 对照组 | 回答的问题 |
| --- | --- |
| 全部合格股票等权 | 完整策略是否优于基础股票池 |
| 入选板块内等权 | 选板块本身是否有效 |
| 入选板块内随机选股，多次重复 | 个股排序是否优于随机选择 |
| 完整策略选股 | 板块与个股选择结合后是否增加价值 |

比较时同时检查股票规模、波动、流动性和市场状态，防止把风格暴露误认为选股能力。

**验收条件：**在线推荐与历史回测共用相同的策略定义；每只候选都有清楚的入选和失效理由；不同策略在相同日期、成本和交易约束下可比较；没有显示增量价值的策略保留为观察筛选器，不升级为操作建议。

## 五、第三阶段：增强板块、龙头和组合分析

**实施进度：**已增加板块相对强度、广度、分化、轮动矩阵、龙头角色分层和自选组合风险透视；历史成分、完整成分均线广度及产业核心所需基本面仍不可核实。详见[第三阶段实施记录](phase3-sector-portfolio.md)。

**目标：**解释机会来自哪里，并识别多个候选是否实质上承担同一种风险。板块页面保留多维证据，单一综合分只作为辅助排序。

| 板块维度 | 方案 | 推荐展示 |
| --- | --- | --- |
| 相对强度 | 比较板块与市场的 5/20/60 日收益及排名变化 | 强度曲线与排名轨迹 |
| 内部广度 | 上涨比例、站上均线比例、创新高比例、成员收益中位数 | 广度趋势 |
| 成交参与 | 成交额占全市场比例、相对历史的放大程度、成交集中度 | 成交参与趋势 |
| 持续性 | 连续活跃天数、回调后的恢复情况、成员之间的接力 | 持续性记录 |
| 内部分化 | 龙头与普通成员收益差、涨跌分布、少数股票贡献占比 | 分化提示 |
| 拥挤风险 | 涨幅集中、波动扩大、相关性上升等可观测代理 | 拥挤观察标签 |

成交参与不直接称为“资金净流入”，除非数据能够支持该口径。可以构建板块轮动矩阵：一个方向展示短中期相对强度，另一方向展示内部广度。板块状态可设为“启动观察、持续走强、内部扩散、明显分化、热度退潮”，先验证标签能否稳定描述行情，再检验其是否改善选股。

龙头分层如下：

| 角色 | 识别依据 | 用途 |
| --- | --- | --- |
| 成交核心 | 成交额份额、持续活跃程度、流动性 | 判断板块交易中心 |
| 价格领涨股 | 多周期相对强度、回调保持、领先启动情况 | 跟踪价格表现 |
| 产业核心 | 收入、盈利、业务地位等基本面证据 | 支持中期研究 |

另外跟踪领涨持续天数，以及其他成员是否跟随。当天涨幅第一只能说明当天领涨，不能自动视作产业龙头。

组合分析增加跨策略去重、行业与题材的双重暴露、持仓相关性、波动贡献、流动性集中和现金比例。持仓权重需有明确的风险预算依据；风险数据不足时降低建议可信度。

页面围绕三个问题组织：当前是什么环境，哪些方向值得研究，每个具体候选的依据和组合影响是什么。描述性标签与经过验证的策略信号应在界面上明确区分。

**验收条件：**能够识别板块是多数成员同步上涨还是少数股票拉动；能够区分三类龙头；能够识别多个板块实际集中于同一主题；任意建议可追溯到输入数据和策略版本。

## 六、第四阶段：持续验证、复盘和策略淘汰

**目标：**保存当时真实产生的信号，持续衡量上线后的效果。流程为“冻结信号 → 模拟执行 → 跟踪结果 → 对照归因 → 定期评审”。

| 环节 | 方案 |
| --- | --- |
| 信号冻结 | 保存候选、排名、入选理由、参数、数据截止时间和策略版本；修订另存新版本 |
| 模拟执行 | 记录可成交性、取消或延迟、实际模拟成交、滑点及成本 |
| 结果跟踪 | 按各策略自己的持有周期统计收益、回撤、成交率和换手 |
| 对照归因 | 区分市场收益、板块选择、个股选择、仓位调整与执行成本 |
| 数据监控 | 跟踪缺失率、板块成分覆盖、不同来源差异和更新时间 |
| 策略监控 | 跟踪候选数量、因子分布、超额收益与风险变化 |
| 版本评审 | 新版本先独立观察，与旧版本在相同条件下比较，再决定替换 |

评估指标按用途选择：选股看同日超额、排序相关性与分组收益；组合看成本后收益、最大回撤和尾部损失；执行看成交率、滑点、容量与换手；概率输出看校准误差以及相对简单基准的改善；稳定性看不同时间、环境及附近参数的表现。

策略状态和转换条件提前约定：

| 状态 | 转换原则 |
| --- | --- |
| 探索研究 | 数据和假设明确，可以复现实验 |
| 历史验证 | 通过独立区间、成本与稳健性检查 |
| 前向观察 | 冻结参数，积累未参与调参的新信号 |
| 正式使用 | 前向结果支持目标用途，风险符合预设约束 |
| 暂停或退役 | 数据失效、执行条件变化，或持续表现不满足预设标准 |

评估长度根据策略频率、持有周期和独立事件数量决定。低频恐慌策略尤其需要按独立市场事件评估，不能仅凭几次盈利确认有效，或凭几次亏损直接淘汰。

**验收条件：**能够还原任意一天实际生成的信号，解释收益来源，识别策略失效与数据故障；每个新版本有独立观察记录，策略可暂停、降级和退役。

## 七、阶段交付与推进顺序

| 阶段 | 核心交付物 | 进入下一阶段的条件 |
| --- | --- | --- |
| 第一阶段 | 可信数据与回测基线 | 时间、组合、成分及验证口径可复核 |
| 第二阶段 | 独立且可比较的策略库 | 候选可解释，板块与个股增量分别可测 |
| 第三阶段 | 板块与组合决策视图 | 能识别主线持续性、内部广度及集中风险 |
| 第四阶段 | 持续验证和策略生命周期机制 | 冻结信号、执行、归因、版本评审形成闭环 |

若资源有限，第一批优先完成板块成分准确化、回测口径修复和选股策略拆分。这三项决定后续研究能否建立在可靠结果之上。
