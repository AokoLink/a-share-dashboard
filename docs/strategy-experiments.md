# 步骤 D 实验登记说明

所有收益实验先运行 `core.experiment_protocol.register`，然后读取数据、筛选和核算。登记 JSON 按内容哈希写入 `_analysis/strategy_experiments/registry/`，记录规则、参数、成本、主要指标、对照、停止条件及代码哈希。报告引用登记文件和其 SHA256；改变规则或参数必须产生新的登记，原结果保留。

本次声明的范围为 2022-01-01 至 2026-08-14，每 20 个交易日一个定期样本，另加入全部已记录恐慌日。追加恐慌日只进入反弹汇总，突破和回调保持定期抽样。上述历史曾参与项目研究，仅作为开发区间，不宣称为独立样本外。

验证起点预先设为 2026-10-01，等待之后真实可用的交易日与前向证据。按标签结束日剔除越过边界的开发样本，设 10 个交易日隔离，并支持扩展开发区间后逐月验证；跨月仍未结束的验证标签单独保留。当前没有这些未来样本，不能提前通过验证。数量门槛及均值为正都不自动升级策略。

| 变体 | 改变内容 | 保留内容 |
| --- | --- | --- |
| base | 原先声明的默认规则 | 原资格、池、排序、持有期 |
| breakout_no_sector | 移除板块条件及板块分 | 突破与量能规则 |
| breakout_no_buffer | 突破幅度门槛由 0.1% 改为 0 | 突破幅度排序与其他规则 |
| breakout_no_volume | 移除量能门槛及量能分 | 趋势、突破和板块规则 |
| pullback_no_depth | 移除回调深度范围及深度分 | 趋势、结构未破、缩量规则 |
| pullback_no_shrink | 移除缩量门槛及缩量分 | 趋势与回调结构 |
| rebound_no_drop | 移除 5 日跌幅门槛及跌幅分 | 恐慌、60 日位置规则 |
| rebound_no_position | 移除 60 日位置门槛及位置分 | 恐慌、5 日下跌规则 |

变体仅供研究运行，不进入每日默认候选或正常冻结。中期配置仍因缺少按披露日可用的财务／估值历史而阻塞，不用价格指标替代。

主要指标为事件簇等权的固定等权份额净超额，基准为同日资格池。辅助报告包括已成交条件下毛／净收益、同板块等权和随机对照、环境及事件分组、成交额和波动暴露、成本敏感性，以及回调与同日突破在**相同回调持有期**下的比较。上证综指仅为指数参考代理，不能称为全 A 可交易基准。

每条原始入选事件都保留。跳空取消的固定份额留现金、不付成交费用；入场或退出行情缺失、日历未覆盖、未到期均单独保存，固定份额收益留空，不作零收益、不再分配给后来可成交的股票。板块随机对照先在 T 日归属池抽取，再检查执行结果，不能按事后可成交名单抽样。

相邻或重叠收益标签按事件簇统计，用事件簇自助抽样给出描述性区间。缺失值数量及有效簇数可查；该区间不是显著性或独立性证明。成本按每边手续费 0.1%、滑点 0.1% 的同一模型核算，并检查 0、0.5、1、1.5、2 倍成本。未知市值、历史 ST／停牌／涨跌停、退市样本和复权执行口径仍作为未解释限制。

主报告保留原数值和负结果；`pipeline.review_strategy_experiment` 生成独立证据评审。历史日缺少板块指标时，即使去板块条件的结果与默认版本相同，也标为 `blocked_feature_coverage`，不把零差异解释为板块条件无效。账户净值及重叠资金预算等待步骤 E。

## 2026-09-30 未封印批次

首个真实每日运行发生在 2026-09-30（运行编号 `b17a4c2f-c5e1-43ce-bee6-4a1718e929a2`，启动 23:57:04，结束 2026-10-01 00:07:17）。该次采集与质量检查通过，`freeze_ready` 为真、研究池无失败代码，突破与回调各算出 7 只、反弹 0 只候选；冻结步仍返回 `skipped_day_changed`，快照未写入，重放包未生成。进程启动时固化运行日为 2026-09-30，封印步执行时墙钟已越过零点，封印日期与运行日不属于同一日历日。运行以 `partial` 结束并返回退出码 1。

该批次在因果上早于结果：其后首个交易日为 2026-10-08，封印时刻领先 7 天，预测本身未被事后信息污染。其不合格是程序性的——判定条件是封印与运行日同属一个日历日，所代理的性质是封印早于下一交易时段开盘，在跨长假边界上前者比后者严格 7 天。此区分只用于说明性质，不构成补记依据。

该批次不补冻、不补建审计包，也不以当前代码重跑后写入前向表。补冻需当前代码复现当时结果，而参与签名之源文件哈希已与当时不同，所得快照不可复现；补建审计包会把当前源码哈希记为 2026-09-30 的来源，属伪造审计证据；以当前代码在当日数据上重跑属回测，不属前向验证。候选仅作为带 SHA256 的非证据归档保留于运行目录，条目已由同一次运行标为 `freshness: historical`、`actionable: false`。

成因是启动时点过晚，而非运行编号本身。需在零点前完成的每日任务应安排在收盘后、远离零点的时间段启动。
