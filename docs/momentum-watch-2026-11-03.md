# 热点延续／修复转强观察池

2026-11-03 增加 `momentum`，策略定义版本为 `stage2-technical-v4-momentum`。原趋势突破、强势回调、超跌反弹的选股规则保持不变。新规则针对“当日强势股被统一涨停过滤”和“修复转强必须满足60日新高或恐慌条件”这两个覆盖缺口，不能据此推断收益已经改善。

## 选股与排序

新池独立于原策略按成交额截取的200只股票池，在每日已采集且符合共同资格的股票范围内筛选。沿用非ST、至少61根日线、成交额至少1亿元和现有过热限制；只放开当日接近涨停这一项观察资格。风险输入缺失仍不入选。

初始价格量能门槛如下，均为待验证的规则参数：

| 条件 | 门槛 |
| --- | --- |
| 当日涨幅 | 不低于对应板块涨停幅度的40%，常见10%/20%板对应4%/8% |
| 收盘位置 | 位于日内区间上方25%；接近涨停的平价日线单独处理 |
| 当日成交量 | 不低于此前5日均量的1.2倍，不含当日 |
| 价格结构 | 收盘不低于开盘与5日均线 |
| 修复标签 | 前5日下跌，或前收盘低于此前20日均价；其余标记强势延续观察 |

行业依据只用决策日可核验的原生行业/子行业关系及当日广度，不把“昨日涨停”等技术分类当成行业热点。有效成员至少5只、活跃数据覆盖至少80%，上涨占比至少60%、中位涨幅至少1%时，视为行业共振并加分。行业数据可用但未达到门槛时排除；行业数据缺失或不可核验时保留价格量能观察候选，明确显示“行业热度待核实”，不加行业分。

分数由当日涨幅相对板块限制、收盘位置、放量程度、行业共振分减风险扣分构成，每组展示前20。相同分数按代码排序。分数不是胜率，新闻、政策、财报与龙虎榜没有进入计算；人工分析使用的这些信息尚未被程序复现。规则没有指定或优先匹配任何股票名单。

## 留档与模拟

每日生成会冻结四套策略，新策略有独立股票池与对照池，原三套策略的池不被涨停股挤占。日线先截断到决策日，未来价格不得影响筛选。归档包含输入、代码、规则版本和完整筛选原因。

新池是观察候选，`actionable=false`。沿用最早次日开盘的研究模拟，高开超过5%或低开达到3%取消，停牌、涨跌停可成交性、费用和执行证据仍按原框架处理。研究持有期为3个交易日，随后开盘退出。公告需要另行核实。默认账户资金配置仍只有原三套策略，新池不会自动分配账户资金；独立前向观察可以跟踪候选。

旧版留档没有评估新策略时，网页显示“未评估”，不会把它误写成当日零候选。同日现行版本真实冻结优先于事后重算；旧版日常留档和历史观察仍保留。
